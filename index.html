        🔔 Rappel iPhone

        Quand te prévenir (une ou plusieurs)

        Chaque rappel est créé dans l'app Rappels avec une alerte, une priorité haute et un drapeau. Le son et la vibration dépendent des réglages de ton iPhone.

        Rappels iPhone

        La cloche 🔔 de chaque tâche crée des rappels dans l'app Rappels via l'app Raccourcis : l'iPhone bascule brièvement vers elle, puis tu reviens ici.

        Créer le raccourci (une seule fois)
        1. Ouvre l'app Raccourcis, touche +, puis nomme le raccourci exactement comme ci-dessus.
        2. Diviser le texte : texte = Entrée du raccourci, séparateur = Nouvelles lignes.
        3. Obtenir l'élément de la liste → Premier élément (le titre).
        4. Obtenir l'élément de la liste → Dernier élément (les dates).
        5. Diviser le texte sur ce dernier élément : séparateur = Personnalisé, avec une virgule « , ».
        6. Répéter avec chaque élément (la liste de l'étape précédente).
        7. Dans la boucle : Obtenir les dates à partir de l'entrée (Élément répété), puis Ajouter un nouveau rappel : titre = le premier élément, alerte = la date obtenue, priorité = Élevée, drapeau activé.
        8. Fin de la boucle. (Facultatif) ajoute ensuite Ouvrir l'app → Rappels, pour que l'app Rappels s'affiche après la création.
        9. Touche OK, puis teste avec le bouton ci-dessus.
        Créer le raccourci de suppression (une seule fois)
        1. Dans Raccourcis, touche + et nomme-le exactement comme ci-dessus.
        2. Scinder le texte : texte = Entrée de raccourci, séparateur = Nouvelles lignes (un titre par ligne).
        3. Répéter avec chaque élément du résultat.
        4. Dans la boucle : Rechercher des rappels avec le filtre Titre · est · Élément de répétition (ajoute aussi Est terminé · Non si tu veux garder les rappels déjà cochés).
        5. Toujours dans la boucle : une action qui supprime les rappels trouvés (cherche « supprimer » + « rappel »).
        6. Touche OK.
        Son et vibration
        1. Réglages iPhone → Notifications → Rappels : active Autoriser les notifications, Sons, et choisis le style Bannières permanentes.
        2. Vérifie que le mode silencieux et les modes de concentration n'étouffent pas Rappels.
        3. Sous iOS 26.2, un rappel peut avoir l'option Urgent (alarme sonore, même en Concentration). Regarde si l'action « Ajouter un nouveau rappel » la propose et active-la ; sinon, active-la à la main dans le rappel.

        Le son et la vibration sont décidés par iOS : la page web ne peut pas les forcer. Un rappel déjà créé n'est pas mis à jour si tu changes l'échéance ensuite.
